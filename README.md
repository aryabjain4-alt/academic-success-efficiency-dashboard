# Academic Success Efficiency (ASE) Dashboard

## Open University Learning Analytics

## 1. Project Overview
This project presents an Academic Success Efficiency (ASE) Dashboard developed using Tableau.

## 2. Project Objectives
- Analyze academic performance.
- Understand learning effort.
- Study student withdrawal by registration timing.
- Compare module performance.
- Explore engagement metrics.

## 3. Tools and Technologies
- Tableau
- Microsoft Excel
- GitHub

## 4. Key Performance Indicators
- Average Academic Performance: 71.85
- Average Learning Effort: 0.1431
- Average ASE Score: 0.7185

## 5. Dashboard Components
- Learning Effort vs Academic Performance
- Withdrawal by Registration Timing
- Average Academic Performance by Module
- Correlation Between Engagement Metrics and Academic Performance
- Distribution of Academic Success Efficiency

## 6. Key Insight
Students with moderate learning effort often achieve high academic performance, as indicated by the dashboard.

## 7. Conclusion
This dashboard helps explore academic performance and learning efficiency.
